# 써클(Circle) PRD

## 1. 한 줄 정의

써클은 파티를 즐기는 20대가 어디에 있든 음악과 놀이로 연결되도록, 몸에 붙이는 스피커 컨트롤러로 이어주는 서비스다.

## 2. 주요 사용자 1명

**파티와 친구 모임을 자주 여는 20대 남성.**
파티 중 음악을 바꾸려고 계속 폰을 꺼내느라 흐름이 끊기고, 자리를 비우거나 인파 속에서 흩어지면 일행과의 연결이 끊기는 것에 지쳐 있다.

## 3. 사용자 시나리오

### A. 자리를 비워도 끊기지 않는 파티
1. 게임 중 편의점에 술을 사러 나간다.
2. 스피커에서 멀어지자 써클이 개인 스피커로 전환돼 같은 곡이 이어서 나온다.
3. 내 차례가 되자 써클이 진동하고, 탭 한 번으로 벌칙 투표에 참여한다.
4. 복귀하면 모든 써클이 반짝이며 다시 합류한다.

### B. 페스티벌에서 일행 찾기
1. 인파 속에서 친구들과 흩어졌다.
2. 써클을 길게 눌러 '찾기 모드'를 켜면 일행 전원의 써클이 같은 색으로 빛난다.
3. 친구에게 가까워질수록 진동이 강해진다.
4. 다시 모이면 진동이 멈추고 원래 모드로 돌아간다.

### C. 파티 후 안전 귀가와 리캡
1. 파티가 끝나고 각자 집으로 흩어진다.
2. 집에 도착해 써클을 탭하면 친구들 써클에 초록불이 켜진다.
3. 전원이 도착하면 앱에 그날의 셋리스트와 하이라이트가 정리된다.

## 4. 만들 화면

**디스플레이: 원형, 지름 6cm (6×6cm)**

1. **그룹 연결** — 써클끼리 맞대면 연결, 멤버 수를 원 둘레의 점으로 표시
2. **파티 홈** — 중앙에 곡 정보, 둘레에 재생 진행 링과 멤버 연결 상태
3. **게임 진행** — 전체 화면 컬러로 차례와 결과를 표시 (예: 걸린 사람은 빨간색)
4. **찾기 모드** — 일행 색상으로 전체 발광, 가까워질수록 링이 차오름
5. **파티 리캡** — 귀가 체크 현황과 오늘의 대표 곡 1개

## 5. 지켜야 할 것 / 안 할 것

**지켜야 할 것**
- 스피커에서 멀어져도 음악과 게임 참여가 끊김 없이 이어져야 한다.
- 재생·스킵·투표·찾기 같은 핵심 조작은 폰 없이 써클 제스처만으로 3초 안에 가능해야 한다.
- 한 화면에는 정보 하나만 두고, 한눈에(1초 이내) 읽혀야 한다.

**안 할 것**
- 위치 정보를 일행 외에는 공유하지 않으며, 찾기·귀가 체크는 사용자가 켤 때만 작동하고 파티 종료 시 자동 해제한다.
- 원형 화면에 긴 텍스트나 목록을 넣지 않으며, 상세 정보는 앱으로 넘긴다.

**권장사항**
- 사각형 레이아웃을 원 안에 넣지 않고, 원형 디스플레이의 가장자리까지 활용하도록 원 형태를 반영한 UI 요소를 적극 사용한다.
- 예: 진행 상태는 둘레를 도는 링, 멤버나 옵션은 원주를 따라 배치한 점이나 아이콘, 탐색은 회전(다이얼) 인터랙션, 텍스트는 곡선을 따라 흐르는 배치.
