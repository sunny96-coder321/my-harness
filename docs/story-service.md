# 써클(Circle) 유저 스토리

## 유저 스토리

1. 파티를 즐기는 20대가 써클 제스처만으로 폰 없이 재생·스킵 등 음악을 조작한다.
2. 사용자가 스피커에서 멀어져도 개인 스피커로 전환되어 같은 곡을 끊김 없이 이어서 듣는다.
3. 사용자가 자기 차례가 되면 써클의 진동을 느끼고 탭 한 번으로 벌칙 투표에 참여한다.
4. 사용자가 써클을 길게 눌러 찾기 모드를 켜면 일행의 써클이 같은 색으로 빛나고, 가까워질수록 진동이 강해진다.
5. 사용자가 집에 도착해 써클을 탭하면 친구들의 써클에 초록불이 켜지고, 전원 귀가 후 앱에서 그날의 셋리스트와 하이라이트를 확인한다.

## 어기면 안 되는 것

1. 위치 정보는 일행 외에는 공유하지 않으며, 찾기·귀가 체크는 사용자가 켤 때만 작동하고 파티 종료 시 자동 해제한다.
2. 재생·스킵·투표·찾기 같은 핵심 조작은 폰 없이 써클 제스처만으로 3초 안에 가능해야 한다.
