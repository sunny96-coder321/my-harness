# Circle 레퍼런스 분석

## 입력

- `docs/prd.md`: 파티 중 음악·게임 연결, 페스티벌에서 일행 찾기, 파티 후 귀가 확인
- `docs/design.md`: JBL 디자인 시스템 참고 자료
- `docs/story-service.md`: 사용자 흐름과 불변 규칙
- `docs/story-work.md`: 레퍼런스 수집·분석부터 디자인 토큰 제작까지의 실제 작업 흐름

## 적용 포인트

1. 찾기 모드는 한 화면에 방향/근접 신호 하나를 우선 노출하고, 원주 링과 색 변화로 가까워지는 상태를 표현한다.
2. 그룹 연결은 참여 멤버 수를 원주 점으로 표시하고, 연결 완료 상태를 한눈에 구분한다.
3. 음악 재생/스킵과 투표는 폰 없이 짧은 써클 제스처로 완료되는 흐름을 키스크린에서 보여준다.
4. 모든 찾기·귀가 관련 화면은 일행만 대상으로 하고 사용자가 켠 상태임을 메타데이터에 기록한다. 파티 종료 시 자동 해제 조건도 명시한다.
5. `docs/design.md`의 JBL 오렌지/블랙 대비와 각진 브랜드 패턴은 참고 자료로만 취급한다. Circle은 원형 디스플레이이므로 원주 링·점·아이콘을 우선하고, 긴 텍스트·목록은 넣지 않는다.

## 게이트 판정: 레퍼런스 반영 포인트 선정

- 반영: 원주형 방향/상태 표시, 그룹 연결 상태, 기기에서 직접 시작하는 간결한 조작.
- 제외: 기본 위치 지도, 상시 위치 공유, PRD에 없는 SOS 기능, 1회 조작 제약을 넘는 복잡한 버튼 시퀀스.
- 판정: 통과. 키스크린 단계로 전달한다.
